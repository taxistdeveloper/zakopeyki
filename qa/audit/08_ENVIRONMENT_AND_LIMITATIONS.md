## 4. Ограничения, требующие устранения для полного прогона всех тестов

1. **Доступ к тестовой базе данных MySQL:**  
   Пять автономных тестовых скриптов и функциональные проверки заказов требуют доступного экземпляра MySQL (`host: 127.0.0.1`, `port: 3306`, `dbname: zakopeyki`). В стандартной песочнице межпроцессное сетевое взаимодействие изолировано. Требуется либо запуск MySQL в доступном для песочницы режиме (или SQLite memory fixture), либо выполнение тестов с параметром `BypassSandbox: true` после согласования.
2. **Наличие раннера PHPUnit 10:**  
   Для прогона 65 файлов в `tests/Unit/Services/` необходим исполняемый файл `tools/phpunit.phar` (версии 10.5.x) либо автономный легкий раннер, совместимый с `TestCase`.
3. **Браузерная среда для UI-тестов:**  
   Поскольку headless-браузер (Playwright/Chrome) не подключен к CLI-окружению, проверки интерфейса на Фазах D/E будут выполняться доказательным программным способом (HTTP GET/POST симуляция, верификация CSRF, заголовков, рендеринга шаблонов, проверки атрибутов форм и валидаторов).
