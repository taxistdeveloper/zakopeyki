## 2. Неизвестные (не удалось проверить в рамках репозитория)

1. Фактические production-значения `debug`, `allow_simulated_payments`, `stub_mode`, наличие секретов webhook'ов.
2. Конфигурация веб-сервера (vhost, принимает ли произвольный `Host`, HTTPS/HSTS, PHP-FPM), версия MySQL/PHP в production.
3. Реальное расписание cron/Supervisor (в репозитории нет crontab).
4. Наличие резервного копирования у хостинга.
5. Объём данных (число пользователей/объявлений/заказов) и нагрузка — для оценки пагинации и поиска.
6. Используется ли в production реальный OAuth-поток Halyk (`fetchAccessToken`) или только виджет; какие документы/договор с Halyk ePay; поддерживает ли Halyk возвраты на карту через API для вашего терминала.
7. Действительно ли «eScrow» в бизнес-описании означает внутренний кошелёк платформы (как в коде) или банковский эскроу-счёт.
8. Соответствие текущих правил (сроки возвратов, `courier_void`, direct без комиссии) публичной оферте `/offer`.
9. Доступность `tmp_home.html` и каталогов `_vas*_extract` через web.
10. Поведение внешних FK при удалении пользователя (каскады заданы частично в рантайме).
