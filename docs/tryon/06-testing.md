# 06 — Тестирование и план этапов

## 1. Принципы
- Без платных запросов в автотестах: HTTP провайдеров — через инжектируемый транспорт (фикстуры JSON ответов из документации), бизнес-логика — через `FakeTryOnProvider`.
- Тестовые результаты всегда `is_test = 1` и с плашкой; никогда не выдаются за AI.
- Запуск: `php tools/phpunit.phar` (существующий suite `tests/Unit`). Результаты прогонов фиксируются фактическим выводом.

| `TryOnServiceAccessTest` | чужой job → 404 для status/result/photo/delete; удалённый → 410 |
| `TryOnServiceDeleteTest` | файлы удалены, строки помечены, повтор идемпотентен, `purgeUser` зовёт провайдера |

## 3. Интеграционные
- `tests/Integration/TryOnApiTest.php` по образцу `ApiRouterTest`: маршруты, конверт ответа, CSRF, 401 гостю.
- Ручная проверка на dev с Genlook `mock: true` (бесплатно) — PHASE 2.

## 4. Нагрузка и регрессия
- Скрипт `bin/tryon_loadtest.php` (только dev, Fake): 50 пользователей × создание/поллинг; метрики — время ответа API, отсутствие двойного захвата заданий воркером, соблюдение `tryon_max_concurrent`.
- Регрессия: полный `tests/Unit` до и после; смоук страниц `/product/{id}` (с `tryon_type` и без), форма объявления, админка.

## 6. UI (PHASE 3), кратко
- Кнопка «Примерить на себе» / «Өзіңізге киіп көріңіз» [перевод согласовать] под кнопкой «Купить», стиль существующих кнопок Tailwind.
- Модалка (на мобильном — полноэкранный bottom sheet, кнопки внизу под большой палец): товар + фото товара (выбор из галереи), подсказки по фото (в полный рост/по пояс, хороший свет, без других людей), `<input type="file" accept="image/*">` + отдельная кнопка «Камера» (`capture="user"`) — камера только по нажатию, клиентское сжатие до 2048 px (экономия трафика), превью, чекбокс согласия со ссылкой на политику, «Запустить», прогресс с этапами и возможностью закрыть окно (задание продолжается; результат доступен при повторном открытии), результат с ползунком «до/после», «Попробовать другое фото товара», «Удалить», «Вернуться к покупке».
- Тексты ошибок по `code`, ретраи поллинга с бэкоффом при плохой сети.
