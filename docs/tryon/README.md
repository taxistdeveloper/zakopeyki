## Принятые решения

| # | Решение | Источник |
|---|---|---|
| A1 | Основной AI API — **Genlook**, резервный — **FASHN** | подтверждено пользователем 2026-11-09 |
| A2 | Self-hosted модели не используются до PHASE 6 (все зрелые модели — Non-Commercial) | аудит, 00-audit.md §9 |
| A3 | Без новой инфраструктуры: MySQL-таблица заданий = очередь, CLI-воркер по cron | правило «минимальное решение» |
| A4 | Фото покупателя хранится вне webroot (`storage/tryon`), отдаётся только владельцу | 04-storage-security.md |
| A5 | Без вебхуков в MVP: воркер опрашивает статус (вебхуки Genlook Try-On API не подтверждены документацией) | 05-providers.md |
| A6 | Значения по умолчанию D1–D6 приняты | подтверждено пользователем 2026-11-09 (переход к PHASE 2) |
